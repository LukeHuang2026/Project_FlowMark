This is a project is a buoy that can float down a river freely. It constantly takes water qualtiy measurements through its four sensors: pH, conductivity, disolved organic matter, and turbidity. Then it sends the data live to a local Python Flask server hosted locally on a computer with cellular, with Ngrok to tunnel the URL. After the buoy is collected from the river, the server analyses the data and finds out where the water quality begins to worsen. Then we know exactly where polutions has come from.

The project wasn't that complicated but there was way too much problems and the whole thing took me a lot of time. Heres a google drive folder that has some demo vids: https://drive.google.com/drive/folders/1_lI01mrRCY5MSKxpBBVdA9OAPT4BEkAj?usp=sharing
